# AndroidVSCode

A native Android development workbench inspired by the VS Code workflow.

## Goal

Build a real Android IDE experience rather than a static VS Code clone.

## Foundation

- Kotlin
- Jetpack Compose
- Android Storage Access Framework
- Workspace architecture
- Editor/workbench separation

## Planned modules

- Explorer
- Multi-file editor
- Search
- Command palette
- Terminal integration
- Git
- Build/run adapters
- Diagnostics/problems
- Settings/themes
- Plugin architecture

## Status

Phase 1: repository foundation and native workbench bootstrap.
