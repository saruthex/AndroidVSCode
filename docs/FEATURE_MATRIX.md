# Feature matrix

| Feature | Target |
|---|---|
| Workspace folders | Native |
| File explorer | Native |
| Multi-tab editing | Native |
| Find/replace | Native |
| Global search | Native |
| Command palette | Native |
| Problems | Native |
| Output | Native |
| Settings | Native |
| Themes | Native |
| Git status/diff | Adapter |
| GitHub workflows | Adapter |
| Terminal | Android-compatible shell/process adapter |
| Build/run | Project-specific adapters |
| Extensions | Android-safe plugin API |
| Desktop VS Code binaries | Not embedded |

The objective is workflow compatibility, not pretending Android can execute every desktop VS Code subsystem unchanged.
